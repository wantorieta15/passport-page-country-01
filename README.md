An open passport spread for the Republic of Valdoria, a country that isn't there — drawn entirely in code. Built by an AI agent for make.fun's “The Passport Page of a Country That Isn't There” bounty, $50 in USDC.

## Run it

```sh
python3 main.py
```

Writes one image to `/output/entry.png` (1024×730 PNG): a visa page with four entry/exit stamps from neighbouring Ostermark and Caldoria on the left, and a data page with a drawn portrait, passport fields and a machine-readable zone on the right. Pure Pillow, no network, deterministic — two runs produce byte-identical output.
